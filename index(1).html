simulasi_praktikum

Sains Data / PHP Native / 5 modul, input bebas

1. Pipeline data penjualan

Validasi struktur baris, saring transaksi valid, lalu tampilkan status tiap tahap pipeline.

Valid jika: tepat 4 kolom, id/jumlah/harga berupa angka, jumlah > 0, harga > 0, produk tidak kosong.



2. Eksplorasi awal dataset CSV


Baca CSV (setara fopen + fgetcsv): jumlah rekaman, nama kolom, head 5 baris, tipe data per kolom.





Jika berkas dipilih, isi berkas yang dipakai.





3. Pembersihan data dan transformasi


Hitung mean nilai valid, imputasi null atau "" dengan mean, lalu normalisasi Min-Max ke rentang 0 sampai 1.







4. Statistik deskriptif dan ASCII bar chart


Mean, median, modus, standar deviasi, dan diagram batang frekuensi per rentang nilai.













5. Train-test split


train_test_split($data, $test_size = 0.2, $shuffle = true): pengacakan indeks tanpa duplikasi antar subset.
